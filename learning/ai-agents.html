Agents LLM

AI Agents

An AI agent is an LLM wrapped in a loop: it reads a goal, decides on an action, calls a tool, observes the result, and repeats until the task is done. This page tracks three points on that spectrum — Hermes, OpenClaw, and Claude.

What it is

Where a chatbot answers a message, an agent pursues an objective across many steps. The core loop is the same everywhere: plan → act (call a tool) → observe → re-plan. What differs between systems is the model doing the reasoning, the set of tools it can reach, how much autonomy it's given, and where it runs.

Why it matters

Agents are how LLMs move from “text in, text out” to actually doing work — editing a codebase, running commands, browsing, calling APIs. The engineering questions become interesting and concrete: how do you expose tools safely, keep the model on track over long tasks, recover from mistakes, and stay in control of what it's allowed to do?

Key concepts

  • Tool use / function calling — the model emits a structured request (a name plus arguments); the runtime executes it and feeds the result back.
  • The agent loop — iterate on plan/act/observe until a stopping condition; the context window accumulates the history.
  • Autonomy vs. oversight — how much the agent can do without asking, and where a human approval step sits.
  • Context management — long tasks overflow the window, so agents summarise, retrieve, or checkpoint state.
  • Deployment — local CLI, background service on a server, or embedded in an app — each with different trust and security trade-offs.

The three I'm looking at

Hermes (Nous Research)

An open-weight model family (Hermes 2 Pro, Hermes 3) fine-tuned from Llama for function calling, structured output, and agentic tool use. Hermes uses a ChatML prompt format with a distinctive XML-tag protocol: tool schemas go in <tools>, and the model replies with <tool_call>{"name": ..., "arguments": ...}</tool_call>, with results returned in <tool_response>. Hermes 3 adds longer context retention, multi-turn coherence, and an explicit internal-monologue / reasoning style. It's the “bring your own model” end of the spectrum — you run the weights and build the loop around them.

OpenClaw

A free, open-source autonomous agent (created by Peter Steinberger, formerly “clawdbot”) that you self-host on your own server. Its interface is a messaging app rather than a terminal, and it's model-agnostic. It codes, browses, remembers across sessions, runs on cron schedules and webhooks, and ships with a large set of integrations. It's described as self-improving because it can write its own new skills to handle tasks it wasn't set up for. The core gateway is MIT-licensed. It sits at the “always-on personal assistant” end of the spectrum.

Claude (Claude Code / Claude Agent SDK)

Anthropic's agent stack. Claude Code is a terminal-based coding agent that reads and edits your repo, runs commands, and uses MCP servers for extra tools, with a permission model gating risky actions. The Claude Agent SDK exposes the same harness — the agent loop, tool handling, context management, permissions — as a library for building custom agents on Claude. It's the “managed harness” end: the loop and safety scaffolding are provided, you supply the tools and the task.
