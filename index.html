Projects

FM Transceiver Application

A desktop application that receives and transmits FM radio signals, with user-configurable parameters for tuning and signal characteristics. Built for the Analog Communications lab at LIU — it turned a fixed bench exercise into something I could experiment with, changing transmission parameters and observing the effect on the received signal without rewiring hardware each time.

Proteus 8 Professional

AI Document Assistant

A PDF analysis tool that runs a local model through Ollama to summarize documents and answer questions about their contents, using PyPDF2 to extract text. Searching a long technical PDF with Ctrl+F only finds exact words, and cloud AI tools mean uploading documents you may not want to send anywhere — running the model locally keeps files on the machine.

Python · Streamlit · Ollama

Self Defense App

A mobile application built during DOT NGO's mobile app development training program, giving users safety information and guidance. My first full mobile app, taking me from interface design through to a working build on a real device.
